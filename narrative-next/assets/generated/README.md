# 正文视觉素材

本目录的位图由内置图像生成工具为正文阅读器单独生成，均为原创的无文字、无人像、无作品徽记背景素材。

## 主题舞台

- `theme-day-stage.webp`：冰蓝彩绘玻璃与白石王家档案厅，预留横排卷题区域。
- `theme-night-stage.webp`：黑曜禁书馆、紫晶裂隙与红蚀。
- `theme-tea-stage.webp`：羊皮纸魔女茶庭、黑瓷与植物压花。

## 场景转场

- `scene-day.webp`：水晶门与晨光王都。
- `scene-night.webp`：雨夜水镜与紫晶断界。
- `scene-tea.webp`：翻开的纸上庭园与茶烟。

## 能力演出

- `ability-skill.webp`：钢铁工具与精密技艺。
- `ability-authority.webp`：破碎黑环与禁忌暗流。
- `ability-blessing.webp`：晶羽与世界光环。
- `ability-magic.webp`：七晶玛那术式。
- `ability-spirit.webp`：灵光、晶蝶与铃花共鸣。
- `ability-racial.webp`：角、鳞与血脉脉冲。
- `ability-martial.webp`：交叉剑压与碎环。

## 特殊面板

- `special-check.webp`：无数字二十面晶骰、天平与概率分岔。
- `special-restart.webp`：碎裂古钟与逆流时间回廊。

生成约束：无文字、无数字、无人像、无商标、无官方作品徽记、无水印；构图需允许正文覆盖并兼容窄容器裁切。
