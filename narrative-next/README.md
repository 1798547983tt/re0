# Re:Zero 正文美化 V2

`narrative-next/` 是完全重做后的维护源目录。旧版 `narrative/` 保持只读；新界面没有沿用旧版视觉实现。

## 直接使用

推荐只导入 `dist/regex-Re0·正文美化-v2.json`。这一条正则同时识别流式生成和完整回复，不需要再导入其他文件。

如果角色卡构建流程要求把流式态和完成态拆开，则改为同时使用：

1. `dist/regex-Re0·正文美化-v2-流式.json`
2. `dist/regex-Re0·正文美化-v2-完成.json`

`dist/regex-Re0·正文美化-v2-suite.json` 是供角色卡构建器嵌入 `regex_scripts` 的两项数组，不是单条正则导入文件。不要同时安装主文件和拆分文件，否则会重复执行。

模型输出规则见 `rules/正文输出格式.md`。该文件采用 `<customize_format>` 写法，正文协议只要求完整的 `<content>` 根；仍然使用 `{人物}「对白」`，根节点不含 `version="2"`，也不要求正文规范生成变量更新尾标签。显示正则只替换正文根，外部变量后缀即使尚未闭合也会原样保留。

## 已完成内容

- 44 位指定人物全部接入专属头像、别名、配色、气泡轮廓、纹样、动态签名和小符号；头像为无白色内框的方形裁切，桌面 90px、窄屏 60px。
- 未收录人物使用姓名首字头像和由姓名稳定生成的通用配色。
- 2–3 字短名强调第一字，4 字及以上短名强调第一、第三字。
- 1–39 卷全部拥有标题，并通过 7 种动态排版族生成对应横排版式；最长卷题会按真实字数自适应窄屏宽度。
- 日／夜／茶三种版面各自拥有独立构图、边框、材质、标题舞台和场景转场图，另有 4 种字体、4 档字号及关闭动态特效功能。
- 一般技能、权能、加护、魔法、精灵术、种族能力、武技各有独立生成图与演出；能力介绍默认展开。
- 检定和死亡回归使用独立生成图；15 张正文素材固定引用 Git 提交 `7bc787761a1489e09f4eb9443b92d19169364475`。
- 对白文字具有低速角色配色流光；静态模式和系统减少动态设置都会关闭动画并保留颜色与结构。

## 预览与构建

- 源码交互预览：`narrative-next/index.html`
- 与交付正则完全相同的打包后预览：`reports/narrative-v2-packed-preview.html`
- 重新生成产物：`node tools/package_narrative_next_regex.mjs`
- 检查产物是否最新：`node tools/package_narrative_next_regex.mjs --check`

正则只修改聊天显示，不改写发给模型的内容。运行时依赖酒馆的 Regex 显示替换与 HTML 消息 iframe；页面核心、人物表和卷标题都内嵌在产物中。头像、Logo 和生成视觉素材均使用固定 Git 提交地址，人物头像另保留备用地址和首字头像降级；字体不可联网时会回退到本机中文字体。

主导入文件严格使用 `/<content>([\s\S]*?)<\/content>/is`，只捕获正文根内部并写入隐藏文本载体。打包前端采用参考“龙族正文美化”的分阶段结构：轻量解析核心、DOM 渲染器、直接启动脚本依次执行；交付 HTML 自身不含可被同一正则二次命中的正文根，也不再显示加载占位。iframe 页面背景保持透明，启动异常时显示明确错误。
