# Re:Zero 正文美化 V2

`narrative-next/` 是完全重做后的维护源目录。旧版 `narrative/` 保持只读；新界面没有沿用旧版视觉实现。

## 直接使用

推荐只导入 `dist/regex-Re0·正文美化-v2.json`。这一条正则同时识别流式生成和完整回复，不需要再导入其他文件。

如果角色卡构建流程要求把流式态和完成态拆开，则改为同时使用：

1. `dist/regex-Re0·正文美化-v2-流式.json`
2. `dist/regex-Re0·正文美化-v2-完成.json`

`dist/regex-Re0·正文美化-v2-suite.json` 是供角色卡构建器嵌入 `regex_scripts` 的两项数组，不是单条正则导入文件。不要同时安装主文件和拆分文件，否则会重复执行。

模型输出规则见 `rules/正文输出格式.md`。协议仍然使用 `{人物}「对白」`，根节点不含 `version="2"`。

## 已完成内容

- 44 位指定人物全部接入专属头像、别名、配色、气泡轮廓、纹样、动态签名和小符号。
- 未收录人物使用姓名首字头像和由姓名稳定生成的通用配色。
- 2–3 字短名强调第一字，4 字及以上短名强调第一、第三字。
- 1–39 卷全部拥有标题，并通过 7 种动态排版族生成对应版式。
- 日／夜／茶三种版面，4 种字体，4 档字号，以及关闭动态特效功能。
- 一般技能、权能、加护、魔法、精灵术、种族能力、武技各有独立演出；能力介绍默认展开。
- 对白文字具有低速角色配色流光；静态模式和系统减少动态设置都会关闭动画并保留颜色与结构。
