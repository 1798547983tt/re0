## 已检查行为

- 常驻概览：地点、时间、主角身份、生命/体力/魔力/精神稳定仪表、展开与收起。
- 开合手势：头部支持鼠标与 Enter/Space；概览非控件区域支持点击；头像、日夜与详情内控件不会冒泡触发整栏开合。
- 分区导航：概览、主角、世界、人际、轮回、事件、线索、行囊、音乐九项均可选择，标题与内容正确；方向键可循环切换。
- 日夜模式：自动日间、手动夜间、恢复自动均可用；宽图和移动图均成功加载。本地验收使用 `?assets=local`，生产包使用固定提交的 GitHub Raw URL。
- 人际交互：人物卡、类别筛选和完整人物抽屉可用；320px 下抽屉变为容器内底部面板。
- 轮回信息：存档快照默认隐藏，确认后只读展示六个根域；死亡记录默认折叠，可单独展开。
- 头像：45 个内置人物按姓名/别名匹配；自定义聊天覆盖与共享头像优先。本地文件选择、裁剪、WebP/IndexedDB 保存、移除均保留；HTTPS URL 输入可用，HTTP 被拒绝。
- 音乐：四首内置曲目、持续 `Audio` 实例、播放/暂停、前后切歌、进度、音量、顺序播放、单曲循环、本地 Blob、HTTPS URL、删除与恢复均有自动化覆盖；桌面浏览器实测顺序切歌和模式切换。
- 头像范围：没有当前聊天 ID 时默认选择共享库，并禁用“当前聊天覆盖”；不会选中一个不可用的选项。
- 键盘与焦点：Escape 关闭头像弹窗并将焦点还给触发头像；主要按钮的可见尺寸不小于 44px。
- 收纳：同一分区同时只展开一个信息组；主题切换、变量重渲染和页面刷新不会丢失当前聊天的展开位置。
- 动态：整栏详情使用 `1fr ↔ 0fr` 连续高度过渡；手风琴使用原节点 `auto 0fr ↔ auto 1fr` 过渡，标签、筛选、分页只局部更新详情面板。
- 列表：动态记录先显示 3 条，再以 5 条为一批展开，可一键恢复紧凑数量。
- 窄屏：九个分区在 420px 以下保持单行横向滑动，当前标签自动进入可见区域；新聊天的信息组默认全部收起，导航与文档均无横向溢出。

## 韧性与安全夹具

通过 `fixture=empty|malformed|stale|hostile` 检查：

- `empty`：空状态安全渲染，主角显示“未记录”。
- `malformed`：错误类型被归一化，不导致页面崩溃。
- `stale`：显示“数据旧”提示并保留最后可用状态。
- `hostile`：`<img onerror>` 与拆分构造的 `<script>` 字符串仅作为文本显示；未产生注入节点，`window.pwned` 未被设置。
- 失效远程头像：图片元素失败后移除，姓名首字仍可见。

## 本轮通过 RED–GREEN 关闭的问题

1. 无聊天 ID 时，头像范围曾同时选中共享与被禁用的聊天覆盖；增加纯函数回归测试后修正。
2. 离线预览缺少空、畸形、旧数据与恶意字符串入口；增加独立夹具选择器及打包安全测试。
3. 窄屏标签轨道暴露原生滚动条；补充回归断言，并在极窄容器改为 3 × 3 可点击网格。
4. 场景图片虽成功下载，却因 `z-index: -2` 位于不透明状态栏背景之后而不可见；新增绘制层回归断言，将场景/装饰层移入状态栏自身 stacking context，并降低内容表面的遮罩强度。随后用生产 GitHub Raw URL 复验日间、夜间、宽屏和移动端图片均可见。
5. 背景图进入正确绘制层后仍被多层内容遮罩压低到约 19% 有效贡献；新增场景强度与面板透明度回归，将图片层提升为完整强度，并改为仅在文字区域使用局部遮罩。
6. 展开详情使用 480px 固定下限，且分区内记录大多同时铺开；新增 UI 状态模块和界面契约测试，实现每分区严格单组手风琴、3＋5 分批列表与按聊天持久化。
7. 420px 以下的 3 × 3 标签网格与换行模式按钮占用过多纵向空间；改为 59px 单行横向标签，并锁定模式按钮不换行。浏览器回归把 320px 默认展开高度控制在 653px。
8. 所有点击都调用 `render()`，清理头像 URL 后执行 `app.replaceChildren(frame)`，导致背景、头像和入场动画整体重启；新增交互契约回归，整栏开合改为常驻详情层，手风琴原地过渡，标签、筛选和分页只更新详情面板。
9. 截图蓝框黑底来自预览/iframe `body`，红框内场景又被状态栏壳、头部与概览实色层遮挡；新增透明表面回归，将外层、壳体、头部和概览改为透明，仅在文字附近保留低强度局部渐变和卡片衬底。
10. 初版手风琴开启动画依赖 `requestAnimationFrame`，后台 iframe 被节流时可能停留在 `aria-expanded=true` 但视觉仍收起；浏览器红测后改为记录 0fr 初始布局再同步切到 1fr，复验严格单组、焦点与内容清理均正确。
11. 移动图仅由 `max-width: 700px` 触发，桌面展开后仍把宽图纵向 `cover`；改为以 `data-details-open` 选择移动构图，桌面收起继续使用宽图。
12. 用户别名表含44条而头像目录有45张，缺少爱蜜莉雅；新增固定45人媒体清单，并为艾米莉亚、艾蜜莉雅等别名显式映射 `爱蜜莉雅.png`。
13. 内置头像曾等待可选 IndexedDB 查询结束才渲染，查询阻塞时没有任何头像资源请求；改为同步绘制内置图，自定义头像异步覆盖。
14. 本地预览的可信内置头像是相对地址，却被用户 URL 的 HTTPS 校验器拒绝；拆分可信内置资源校验，仍拒绝用户输入的 HTTP、`data:` 与 `javascript:`。
15. 相对音乐地址会被浏览器规范化为绝对地址，字符串比较导致暂停续播误判为换源；播放器改按曲目 ID 判断换源，并新增续播不重载回归。
16. 局部切歌后播放器标题更新、手风琴摘要仍保留上一首；新增摘要绑定并与播放状态一起原地同步。
