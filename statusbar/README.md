# Re:Zero 全变量日夜动态状态栏

这是独立于创角向导的消息内只读状态栏。它完整覆盖 `酒馆助手脚本-ZOD.json` 的八个顶层领域与 172 个声明叶模式，并把未知透传字段保留在诊断页。

## 本地预览

在仓库根目录运行：

```powershell
python -m http.server 4174 --directory statusbar
```

打开 `http://127.0.0.1:4174/?assets=local`。本地页面在未检测到 Tavern Helper/MVU 时会显式标记为“离线预览”，并加载 `data/sample-state.json`；打包版本不会携带这个样例入口。省略 `assets=local` 时会验证固定提交的 GitHub 生产 URL。

可以追加 `fixture=empty`、`fixture=malformed`、`fixture=stale` 或 `fixture=hostile` 检查空数据、畸形值、旧数据标记和恶意文本的安全降级。

## 交互

- 顶部概览常驻；点击场景头部或概览信息条的非控件区域开合九个分区，不再显示单独的“展开档案”按钮。头像、日夜、标签、筛选和分页等控件不会误触整栏开合。
- 整栏详情使用连续高度过渡，标签、手风琴、筛选和分页只更新详情面板；不会因每次点击重建整棵状态栏。减少动态偏好下会自动取消非必要动画。
- 日夜默认跟随 `世界.当前时间.时段`。展开后，完整模式工具条位于当前分区标题右上方；收起后保留一个 44px 日夜快捷按钮。“恢复自动”撤销手动覆盖。
- 详情采用三级收纳：整份档案、当前分区、分区内信息组。同一分区同时只展开一个信息组；桌面新聊天默认展开核心组，700px 以下默认全部收起。
- 人物、事件、线索、物品等动态列表首次显示 3 条；“再显示 5 条”分批展开，“收起列表”恢复紧凑视图。
- 活动分区、总开关、每个分区的展开组和列表显示量按当前聊天保存在浏览器本地；新聊天使用紧凑默认值。窄屏九个分区使用单行横向滑动标签。
- 主角和人物头像可点击编辑。本地文件只在浏览器内裁成 WebP 并写入 IndexedDB；HTTPS URL 以 URL 记录保存，组件不会自动上传本地图片。
- 头像先读取当前聊天覆盖，再读取跨聊天同名库，最后退回姓名首个字素。
- `轮回.存档点.状态快照` 需要显式确认；`菜月昴死亡记录`、`容貌`、`衣着` 默认折叠。
- iframe 页面、状态栏外壳、场景头部和概览信息条均保持透明；可读性由文字附近的局部渐变与内容卡片承担，不用整块黑色底或高强度全幅蒙层遮住场景图。

## 边界

状态栏不包含变量写入 API，不执行死亡、回档、Schema 迁移或人物资料维护。宿主依赖与真实酒馆待验收项见 `RUNTIME.md`。
