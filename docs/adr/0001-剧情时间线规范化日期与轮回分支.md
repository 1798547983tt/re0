# 剧情时间线规范化日期与轮回分支

本项目决定用每年12个月、每月30天的专用规范历，把菜月昴初次穿越固定为魔女历1000年01月01日，并以统一取值平滑原文“约一个月、约两个月半、一年多”等相对时长。因为正传没有完整月历，所有换算日期必须标记为“编辑演算”或“历史估算”；第01卷的“塔木兹月14号”保留为原文备注但服从用户锚点。死亡回归只沿用重置点的世界日期、以轮回分支标识，不累加昴的主观记忆时间；历史回溯和试炼幻境单列时间层，不推进主线。

## 统一取值

半天=0.5日；几天=3日；一周=7日；约/将近一个月=30日；约两个月=60日；约两个半月=75日；一年=360日；一年多=390日；一年半=540日；近三个月=90日。

## 跨卷连续性修订

第25卷主线按约定落在魔女历1001年04月26日，第26卷承接为04月27日至04月29日。为消除代理初稿把帝国篇后段误锚回1000年的倒退，第27至39卷主线日期统一平移390日，形成1001年05月至06月的连续序列；该平移只作用于编辑演算日期，不改写历史回溯、试炼幻境或轮回分支的时间层。

## 摘要排版与审查修订

为改善阅读，39个TXT统一采用“单一卷标题闭合标签 + 事件纯文本小标题”的版式：只保留卷标题的 `<卷标题>...</卷标题>`，事件中的日期、时段、起因、经过、结果、在场人物、来源均使用普通标签式小标题，不再为每个字段添加XML标签。内容审查以原卷章节和近似行号为回查依据，优先修正行动者归属、事件结果、轮回分支与历史回溯混淆，并补足改变策略或揭示新信息的关键节点。
