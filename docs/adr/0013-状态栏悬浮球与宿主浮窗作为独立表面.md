# 状态栏悬浮球与宿主浮窗作为独立表面

星屑碎片状态栏采用 Tavern Helper 脚本在 SillyTavern 宿主文档中创建单例悬浮球与浮窗/移动抽屉；它与已有的消息内状态栏共用只读状态映射和头像协议，但不把 `position: fixed` 伪装在消息 iframe 里，也不把宿主入口写进消息正文。悬浮球只负责命令入口，面板负责读取当前消息楼层变量并按事件刷新。这样可以让用户在切换消息和聊天时持续访问状态，同时把跨 iframe 生命周期、宿主私有 DOM 和失败降级的复杂度明确留在新脚本边界内。

悬浮球自由拖动且不自动吸边；拖拽位置按归一化视口坐标保存在浏览器本地，拖拽过程通过 `data-dragging` 和位移反馈表达，点击与拖动由 pointer gesture 仲裁。面板关闭只隐藏表面，不清除最近一次成功读取的状态；脚本销毁时统一移除节点、事件监听、计时器和对象 URL。
