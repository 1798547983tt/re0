# 状态栏 NPC 头像复用正文注册表

星屑碎片状态栏的关系人物头像复用 `narrative/data/character-registry.json` 的稳定 ID、别名归一化和 `portraitKey` 解析逻辑，并使用同一仓库 `narrative/assets/avatars/` 下按提交固定的头像资源。新状态栏不维护第二套人物别名表，也不根据相似字符串猜测头像；未命中或存在歧义时回退姓名首字。头像采用按需加载，避免脚本启动时请求完整 roster。

主角和任意人物的用户自定义头像仍由独立的浏览器本地头像库管理，可按跨聊天共享或当前聊天覆盖保存；上传文件先在本地裁切/压缩，既不写入 `stat_data`，也不自动上传到 GitHub。该取舍保持正文正则、消息内状态栏和宿主碎片状态栏的 NPC 视觉一致，同时保留原创主角的个性化入口。
