# Re:0 创角向导风格原型

这是一个明确标注为 `PROTOTYPE` 的一次性 UI 试验，用来回答：五页式创角向导应该采用哪种视觉语言？

## 运行

在 `prototype/` 目录启动一个静态服务器：

```powershell
python -m http.server 8765
```

打开 <http://127.0.0.1:8765/re0-style-previews.html?variant=A>。

可用 `?variant=A` 到 `?variant=E` 直接分享某个风格；页面底部切换器、风格标签、左右方向键都可以切换。

## 五种方向

- **A · 月蚀档案**：暗色档案页、金色刻线、适合酒馆嵌入与严肃的状态面板。
- **B · 王选仪典**：明亮纸张与王选文书感，强调正式、清洁的信息层级。
- **C · 魔女茶会**：紫色玻璃、圆角与派对式气氛，强调角色灵感与 AI 帮填。
- **D · 死亡回归终端**：青绿色终端、状态写入与轮回数据感，强调系统性。
- **E · 雪原绘卷**：纵向绘卷、留白与章节感，强调翻页与叙事沉浸。

卷与事件索引由仓库 `剧情总结/第01卷.txt` 至 `第39卷.txt` 生成到 `re0-story-data.js`（每卷包含全部已识别事件与时间）；原图副本位于 `prototype/assets/`，未覆盖用户原始素材。

本原型不持久化、不调用真实 AI、不写入酒馆；选定方向后再重写为生产实现。
